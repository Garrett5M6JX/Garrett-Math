# Garrett Math — lote V19 a V21

## V19 — Roles y permisos administrativos
- Conserva `admin_users` como lista de superadministradores.
- Añade roles delegados separados: editor de contenido, coordinador docente y analista.
- La asignación y revocación se realiza mediante funciones SQL que verifican al superadministrador en el servidor.
- La gestión de contenido usa `has_admin_permission('content.manage')` y políticas RLS.
- El registro de auditoría y la gestión de roles quedan reservados al superadministrador.
- Añade la pantalla de gestión de usuarios y permisos al panel.

## V20 — Centro de contenido
- Filtro por estado editorial.
- Búsqueda por título, ID y campos de relación.
- Corrige el guardado para escribir el contenido en la columna JSONB `data`, manteniendo campos relacionales y metadatos de cada tabla.
- Exige las relaciones necesarias para grados, unidades, temas y lecciones antes de guardar.

## V21 — Editor visual de lecciones
- Campos visuales para objetivo, duración y resumen de una lección.
- Mantiene el editor JSON avanzado para secciones, ejemplo resuelto, ejercicios, prerrequisitos y demás estructura.
- No publica automáticamente: el estado editorial seleccionado se conserva y el contenido puede quedar como borrador.

## Requisito de activación
La pantalla de roles delegados y los permisos granulares requieren ejecutar manualmente `supabase/admin_v19_roles.sql` en Supabase SQL Editor. No se ejecutó ninguna migración desde este cambio. Hasta aplicar el SQL, el superadministrador heredado conserva el acceso anterior; los roles delegados todavía no se pueden asignar.

## Seguridad / alcance
- No se añadió Google OAuth.
- No se expuso `service_role`, claves API ni secretos en el navegador.
- Los módulos docentes y analíticos tienen roles reservados, pero sus herramientas todavía no se habilitan con este lote.
- No se migró ni modificó información existente.
