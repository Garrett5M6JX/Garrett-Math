# Garrett Math — lote V22 a V24

## V22 — Validación y editor de contenido
- Validador de lecciones antes de pasar a revisado o publicado.
- Comprueba objetivo, duración, secciones, ejemplo resuelto, ejercicios, resumen y prerrequisitos.
- Los borradores se pueden guardar sin publicar; la validación estricta se exige para estados revisado/publicado.
- Errores de estructura se muestran en el panel sin interrumpir la aplicación.

## V23 — Docentes y aulas
- Directorio de cuentas cuyo rol docente fue asignado de forma confiable en Supabase Auth.
- Creación administrativa de aulas asociadas a un docente.
- Código de acceso aleatorio por aula.
- RLS: el docente solo consulta y administra sus aulas; los administradores con teachers.manage pueden gestionar el conjunto.
- La asignación de rol docente no se realiza desde el navegador ni se confía a metadatos editables por el usuario.

## V24 — Estadísticas
- Indicadores agregados de cuentas, perfiles familiares, docentes, aulas, progreso y lecciones.
- Consulta protegida por analytics.view.
- No se exponen nombres, correos ni métricas individuales de menores.

## Activación de base de datos
1. Si todavía no se aplicó, revisar y ejecutar primero `supabase/admin_v19_roles.sql`.
2. Después revisar y ejecutar `supabase/admin_v23_v24_teachers_analytics.sql`.
3. No se ejecutaron migraciones desde esta PR.

## Requisitos para docentes
Las cuentas docentes deben tener `app_metadata.assigned_role = "teacher"`, asignado por un administrador confiable desde el entorno administrativo de Supabase o un backend seguro. No se permite que el usuario se otorgue ese rol desde el cliente.

## Límites
- La creación de aulas y estadísticas requieren las migraciones.
- La incorporación de estudiantes mediante códigos de aula y el portal operativo del docente se desarrollarán en una versión posterior.
- No se añadió Google OAuth ni dependencias nuevas.
