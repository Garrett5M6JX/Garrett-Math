# Garrett Math — V25 a V27

## V25 — Seguridad y auditoría
- Consulta de hasta 200 eventos recientes de audit_log.
- Búsqueda y filtro por acción.
- Muestra fecha, entidad, actor y resumen.
- Consulta el nivel AAL de la sesión mediante Supabase MFA.
- Acceso exclusivo al superadministrador.
- Advierte que audit_log solo contiene operaciones que escriben eventos explícitamente.

## V26 — Centro de control Garrett AI
- Estado del servicio, modelo, límites y consumo agregado.
- Actualización manual de datos.
- Guía de variables de entorno de Vercel.
- Solo lectura: no muestra ni permite editar secretos en el navegador.
- La API existente exige usuario en admin_users (superadministrador).

## V27 — Mapa de aprendizaje
- Navegación por etapa y tema del catálogo.
- Consulta prerrequisitos, temas dependientes y lecciones asociadas.
- Usa el catálogo y sus identificadores estables; no duplica contenido.
- Vista de solo lectura. La edición de conexiones se deja para una fase con validación y persistencia transaccional.

## Seguridad / migraciones
- No se ejecutan migraciones automáticamente.
- Los módulos V25–V27 usan estructuras existentes: audit_log, auth MFA y catálogo curricular local.
- No se añaden permisos privilegiados ni se amplía RLS.
- La auditoría muestra solo eventos instrumentados; no promete registrar acciones que no escriben audit_log.
